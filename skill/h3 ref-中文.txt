# 全参考模式改写输出格式指南

本指南说明在全参考模式下，改写输出如何组织与撰写。

全部六个改写章节均以英文撰写。仅在 `<d>` 内的对话与歌词，以及画面中可见的文字，保留其原始语言。

**描述详细度：** 尽可能把 `detailed_description` 写得详细、明确。针对每个镜头，清晰交代当前构图、主体外观与位置、环境与光照、动作与状态变化、运镜、当前声音，以及被引用内容实际出现或生效的位置。避免把描述缩减为情节概要或参考关系清单。

> 镜头、运镜、说话人、对话与普通声音的基本格式与《视频提示词撰写指南》(T2VA / I2VA / FL2VA / L2VA) 共用。本指南聚焦全参考模式特有的参考标签、分析章节与格式差异。

## 1. 整体结构

一份完整的改写输出由以下顺序的六个章节组成：

| 章节 | 用途 |
| --- | --- |
| `subject_definitions` | 定义被引用内容及其参考标签 |
| `summary` | 概述任务类型、目标视频与主要参考关系 |
| `retention_analysis` | 说明被引用内容如何被保留、迁移或复用 |
| `detailed_description` | 按播放顺序描述画面、动作、镜头、声音与对话 |
| `overall_soundscape` | 概述环境氛围与物理声音 |
| `non_diegetic_music` | 描述仅观众可闻的背景音乐 |

## 2. 参考标签与定义（`subject_definitions`）

全参考改写使用四类标签来标识被引用内容的来源与作用：

| 标签 | 含义 |
| --- | --- |
| `<Subject N>` | 从参考素材中抽象出的可见内容，可在目标视频中被复用或修改 |
| `<Picture N>` | 用作具体目标帧或镜头规划锚点的参考图像 |
| `<Video N>` | 提供剪辑源、续接起点或整片时间结构的参考视频 |
| `<Audio N>` | 被复制或被引用的音频信号 |

> 一旦为某部分内容分配了参考标签，它在 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 以及各音频章节中始终保持同一含义。

`subject_definitions` 为每一部分后续需要单独追踪的被引用内容给出定义，例如一个人物、一处环境、一段源视频的结构或一条音轨。为每一项单独占用一行，说明其标签所指的内容、它的参考作用以及需要遵循的主要特征；当出处需要被明确时，注明对应的源素材。若 `<Picture N>` 或 `<Video N>` 仅用于标识另一个被引用项的来源、后续不会被单独分析或使用，则在该项的定义中引用它即可，不必单列一行。`retention_analysis` 记录每个被引用项出现的位置，以及它是被完整保留、部分保留、迁移还是复用。

### 2.1 `<Subject N>`

`<Subject N>` 用于可复用的可见内容，包括：

- 人物、动物或物体
- 场景、背景或环境
- 服装、道具、界面或视觉效果
- 风格、动作、表情或姿态

它代表的是一段将在目标视频中实际使用的内容单元，而不是源文件本身。一个主体可由多个参考素材共同定义，一个参考素材也可以提供多个主体。

```text
<Subject 1> 是 <Picture 1> 中留着黑色长发、身穿蓝色开衫、佩戴细银项链的年轻女子。
```

当同一主体来自多个素材时，合并其来源并说明每个素材提供的内容：

```text
<Subject 1> 是外貌来自 <Picture 1>、行走动作来自 <Video 1> 的女子。
```

### 2.2 `<Picture N>`

当参考图像本身作为某个镜头的首帧、关键帧、尾帧、编辑后关键帧或构图锚点时，使用独立的 `<Picture N>`：

```text
<Picture 2> 是 [Shot 1] 的首帧，画面中一名女子坐在咖啡馆窗边。
```

若图像仅用于定义角色、场景、服装或风格，则不要单独创建图片条目，而应在对应的 `<Subject N>` 定义中引用该图像来源。

当图像作为分镜或镜头规划参考时，说明它对应哪些镜头，以及它提供了哪些规划信息：

```text
<Picture 3> 是 [Shot 1] 与 [Shot 2] 的分镜参考，定义它们的视点、主体位置与镜头顺序。
```

### 2.3 `<Video N>`

`<Video N>` 专用于整片级关系，例如：

- 剪辑一段原始视频
- 从原始视频的结尾处续接
- 引用原始视频的运镜、剪辑、节奏或时间结构

```text
<Video 1> 是目标视频剪辑所用的源视频。
```

若参考视频中的人物、物体、场景、动作或效果被作为可见内容复用，它仍归属于 `<Subject N>`。`<Video N>` 标识的是素材来源或结构来源，并不替代主体标签。

### 2.4 `<Audio N>`

`<Audio N>` 表示一份独立的音频素材，或参考视频中已启用的同步音轨。常见用法包括：

- 复制全部或部分音频信号
- 引用某种背景音乐风格
- 引用说话人的音色与表达方式
- 使用原始音频中的对话、歌词或音效
- 引用节拍、节奏或音频连续性

当某个 `<Audio N>` 明确对应某个目标说话人时，在该定义中复用该说话人的全局 ID：若说话人对应某个已定义主体，写作 `<Subject N> (Sx)`；否则使用一段稳定的声音描述并在其后接 `(Sx)`。该 ID 来自目标视频的全局说话人顺序，不在音频定义中独立分配或重新编号。说话人编号规则见 5.4 节：

```text
<Audio 1> 是 <Subject 1> (S1) 的音色参考。
```

当同一份音频素材承担多个作用时，用一句自然的话描述这些作用，而不要另建子章节。

### 2.5 来自同一参考视频的画面与音频轨道

`<Video N>` 与 `<Audio N>` 各自独立编号。每个序号仅表示该标签在自身类别内的顺序，并不编码两个类别之间的配对关系。因此同一个参考视频可能对应 `<Video 1>` 与 `<Audio 2>`；序号不同并不妨碍它们来自同一份源素材。

普通参考视频并不会仅仅因为文件中含有声音就产生 `<Audio N>`。

`<Audio N>` 的定义主要说明该音频的作用，不必指明它来自哪个 `<Video N>`。只有在需要消除出处歧义时才说明共用来源，例如：

```text
<Video 1> 是目标视频剪辑所用的源视频。
<Audio 2> 是 <Video 1> 的同步音轨，并在目标视频中被复用。
```

## 3. `summary`

本章节用一段简短的英文文字概述目标视频及其参考关系。它以方括号括起的任务类型前缀开头：

```text
[reference generation] ...
[video editing + reference generation + audio reuse] ...
```

根据每个参考素材在目标视频中实际扮演的角色选择任务类型：

| 任务类型 | 适用情形 |
| --- | --- |
| `keyframe completion` | 图像作为目标视频的首帧、关键帧、尾帧、编辑后关键帧或其他具体帧锚点 |
| `reference generation` | 图像、视频或音频素材为角色、场景、风格、动作、运镜、分镜等提供生成指导，但本身不作为具体帧，也不作为被剪辑或被续接的源视频 |
| `video editing` | 已有源视频被直接修改；编辑图像或在静态关键帧之间生成不属于此类型 |
| `video continuation` | 新内容从已有源视频继续、延伸、恢复或转出 |
| `audio reuse` | 同一音频信号被全部或部分复用 |
| `audio reference` | 音频信号未被直接复制，仅引用其音乐风格、音色、对话或歌词内容、音效质感、节拍或连续性 |

当任务同时满足多种关系时，用 ` + ` 连接任务类型，且不要重复同一类型。例如，从源视频续接并将一张图像用作尾帧，写作 `[video continuation + keyframe completion]`。剪辑源视频并保留其原始音频，可写作 `[video editing + audio reuse]`。

仅仅存在视频或音频，并不会自动产生对应的任务类型。若参考视频只提供运镜、剪辑或节奏，通常归入 `reference generation`。只有当该视频被直接剪辑或续接时，才使用 `video editing` 或 `video continuation`。

剪辑源视频时，若其原始音频仍然可闻，也应同时使用 `audio reuse`。续接源视频而不直接复制音频信号时，若新音频只是延续原音轨的可闻特征，则使用 `audio reference`。

summary 使用先前定义的 `<Subject N>`、`<Picture N>`、`<Video N>` 与 `<Audio N>` 标签，描述主要主体、镜头流程以及各参考素材的作用。不要在本章节引入新的参考标签。

对于视频剪辑任务，任务类型前缀之后的 summary 以如下方式开头：

```text
目标视频是 <Video 1> 的剪辑版本。
```

## 4. `retention_analysis`

本章节说明每一部分被引用内容在目标视频中如何被保留、迁移、复制或引用。每个参考标签占用一行，并保持 `subject_definitions` 中确立的含义。

### 4.1 可见内容

`<Subject N>`、`<Picture N>` 与 `<Video N>` 使用以下关系标记。这些标记是输出格式中的固定英文值：

| 关系标记 | 含义 |
| --- | --- |
| `fully_preserved` | 被引用内容的既定作用被完整保留 |
| `partially_preserved` | 被引用内容仍被使用，但部分既定特征被改变或仅被部分保留 |
| `attribute_transfer` | 被引用的特征被迁移到另一个可辨识的目标主体上 |
| `weak_reference` | 仅保留风格、类别、构图或氛围上的大致相似 |

主体条目：

```text
<Subject 1>（出现在 [Shot 1]、[Shot 3]）：fully_preserved - ...
```

图片条目：

```text
<Picture 2>（[Shot 1] 首帧）：fully_preserved - ...
```

视频结构条目：

```text
<Video 1>（剪辑与节奏结构）：weak_reference - ...
```

### 4.2 音频

`<Audio N>` 使用以下关系标记：

| 关系标记 | 含义 |
| --- | --- |
| `fully_copy` | 完整的源音频作为目标视频完整的最终音轨 |
| `partially_copy` | 仅复制时间线的部分区段或选定的音频层，或在复制后新增、移除、替换了其他声音 |
| `reference` | 信号未被直接复制，仅引用音色、节奏、音乐风格、对话内容或声音质感 |
| `weak_reference` | 仅保留类别或氛围上的大致相似 |

```text
<Audio 1>: fully_copy - <Audio 1> 被 1:1 复用为目标视频完整的最终音轨。
```

```text
<Audio 2>: reference - 目标说话人遵循 <Audio 2> 的音色与克制的表达方式，但不复制原始信号。
```

仅在 `subject_definitions` 中已为该标签定义的参考作用范围内选择关系标记。不要把目标视频中新增的动作、背景或情节事件视为参考保真度的损失。

## 5. `detailed_description`

这是全参考改写的正文部分。它按目标视频的播放顺序逐镜头描述画面、动作、声音与对话，并在适用处插入参考标签。

### 5.1 基本格式

基本格式遵循《视频提示词撰写指南》(T2VA / I2VA / FL2VA / L2VA)：

- 正文以英文撰写。对话、歌词与可见文字保留其原始语言。
- `[Shot 1]` 标记开场镜头，不带时间戳。后续镜头使用 `[Shot N] At MM:SS.mmm, ...` 标记剪辑时间点。
- 在当前镜头内以自然的英文书写运镜，包括需要表达的运镜类型、幅度与速度。
- 为人声来源分配稳定的 `(S1)`、`(S2)` 及后续 ID。对话与歌词写作 `<d>[Language] ...</d>`。
- 对于跨越剪辑点的对话、被视频结尾截断的语音，以及跨镜头的连续音频，使用 `<scenetrans>`、`<cutoff>` 及相应的连续性描述。

关于运镜词汇、群体说话、画外音、跨剪辑点对话与可见文字的完整规则与示例，参见《视频提示词撰写指南》(T2VA / I2VA / FL2VA / L2VA)。

### 5.2 全参考模式的差异

| 维度 | T2VA | 全参考模式 |
| --- | --- | --- |
| 主要字段 | `integrated_multimodal_description` | `detailed_description` |
| 风格开场 | 写在 `[Shot 1]` 之后 | 在 `[Shot 1]` 之前用一到两句英文确立 |
| 参考信息 | 不使用全参考标签 | 在 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 首次出现处及其作用适用处插入 |
| 音频关系 | 描述目标视频自身的声音 | 在对应镜头或音频阶段引用 `<Audio N>`，并说明该信号是被复制还是被引用 |

开场示例：

```text
目标视频采用电影感、文学化的音乐录影带风格，光线柔和，色调略微低饱和。
[Shot 1] 场景开场于一条拥挤的城市街道……
[Shot 2] At 00:09.000, 镜头切至极特写……
```

对于生成任务，`detailed_description` 通常为 350-500 个英文单词。对话密集的内容优先完整容纳口语时间线，而不是机械地凑够词数。视频剪辑类的描述随源视频的复杂度伸缩，不必遵循生成任务的词数区间。单个镜头并不自动意味着描述可以更短；应根据各镜头的信息量把细节分配到多个镜头上。

### 5.3 在镜头中使用参考标签

某个重要的 `<Subject N>` 首次清晰出现时，在镜头中实际可见的范围内描述它被引用的特征、在画面中的位置以及当前动作。后续镜头继续使用同一标签，无需重新定义该标签所指的内容。

对具体帧锚点使用自然的表述：

```text
镜头从 <Picture 1> 开始
镜头的关键帧对应 <Picture 2>
镜头结束于 <Picture 3>
```

剪辑或续接原始视频时，在源片段状态、结构或续接关系适用之处自然地引用 `<Video N>`。在音频关系生效的镜头或语义阶段引用 `<Audio N>`。

### 5.4 说话人、音频来源与对话

基本的说话人 ID 与 `<d>` 格式遵循 T2VA。当被引用主体实际开口说话时，同时保留画面参考标签与说话人 ID：

```text
<Subject 2> (S1) 转向那名女子说道，<d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>
```

`<Subject N>` 标识被引用的主体，而 `(Sx)` 标识实际说话人。主体说话时，写作 `<Subject N> (Sx)`。若同一主体在画外说话，沿用同一形式并标注为 `off-screen`。当说话人不对应任何已定义主体时，使用一段稳定的声音描述并在其后接 `(Sx)`。

当语言内容只是被直接复用的 BGM 或完整配乐中的一个提示点，且没有任何人物、角色、旁白或其他独立人声来源实际发出它时，使用 `<Audio N>` 作为可闻来源，不要额外虚构 `(Sx)`。若由具体人物、角色、旁白或其他独立人声来源发出该声音，则为该来源分配并复用 `(Sx)`：

```text
当 <Audio 1> 唱到 <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d> 这一句时，<Subject 1> 做出相应的手势，但不会成为独立的说话人来源。
```

当参考音频中的对话、旁白或歌词被直接复用，或输入提示词明确要求重演时，在 `<d>` 内保留确切的原始文字与原始语言。对于无法听清的片段，写作 `[unclear]`，不要猜测或转述。标点统一为表达句子所需的基本书面符号，例如 `,`、`.`、`?`、`!`；去除重复的波浪号、表情符号、项目符号以及重复或装饰性的标点。完整的陈述句、疑问句与感叹句分别在 `</d>` 之前以 `.`、`?`、`!` 结尾。

当仅引用音色、节奏、情绪或表达方式时，不要把参考音频中的原始对话带入目标视频。

按目标视频中实际人声事件的出现顺序，一次性分配 `(Sx)`。在 `detailed_description` 的每个实际人声事件处复用对应的 ID；在 `subject_definitions` 中绑定到某个目标说话人的 `<Audio N>` 定义同样复用同一 `(Sx)`，但绝不独立分配新的 ID。不要在 `retention_analysis` 中书写 `(Sx)`。仅存在于被直接复用的 BGM 或完整配乐中的语言提示点使用 `<Audio N>`；由具体人物、角色、旁白或其他独立人声来源实际发出的声音使用 `(Sx)`。

## 6. `overall_soundscape` 与 `non_diegetic_music`

这两类声音的定义遵循《视频提示词撰写指南》(T2VA / I2VA / FL2VA / L2VA)。

`overall_soundscape` 概述整片的环境氛围与物理声音。与特定镜头同步的对话、歌唱与声音事件仍保留在 `detailed_description` 中：

```text
overall_soundscape: 安静的室内房间底噪与低沉的通风声贯穿整片。
```

`non_diegetic_music` 描述角色听不到、仅观众可闻的背景音乐。存在音乐时，说明其配器、速度与力度发展：

```text
non_diegetic_music: 一段克制的钢琴独奏，速度缓慢，下方衬以持续的低音大提琴，没有渐强。
```

使用参考音频时，只在与其可闻层次相匹配的章节中说明复制或引用关系：环境声与音效归入 `overall_soundscape`，仅观众可闻的配乐归入 `non_diegetic_music`。若同一份音频同时提供两类内容，则在各自章节中描述对应的关系：

```text
overall_soundscape: 从 <Audio 1> 复制而来的环境层次贯穿目标视频。
non_diegetic_music: <Audio 2> 被直接复用为完整的仅观众可闻配乐。
```

完整对话与歌词只写在 `detailed_description` 的 `<d>` 内；不要在这两个章节中重复书写。

## 7. 完整示例

<details>
<summary>展开完整示例</summary>

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的咖啡馆环境，具有裸露的砖墙、配花纹靠垫的橙色簇绒沙发、一块霓虹灯牌和一张木质咖啡桌。
<Subject 2> 是 <Picture 2>、<Picture 3> 与 <Picture 4> 中那只毛茸茸的白色萨摩耶，有着厚实的白毛、立耳、深色鼻子和卷曲的尾巴。
<Subject 3> 是 <Video 1> 中的年轻金发女子，留着金色长发，身穿浅粉色卷袖衬衫。
<Subject 4> 是 <Video 2> 中的年轻男子，留着短卷棕发，身穿带抽绳的深灰色连帽衫。
```
