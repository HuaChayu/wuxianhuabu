# 无限画布（wuxianhuabu）

基于 SwiftUI + MLX 的本地多模态视频/图像生成应用，macOS 原生运行，主打**无限画布节点式工作流**：节点即资源，连线即生成，全程本地推理，无需云端 API。

核心生成主线为 **MiniMax H3 视频生成**，同时集成 HiDream 图像等模型，构成可自由组合的多模型创作画布。

## 核心特性

### H3 视频生成（主线）

- **两段式生成管线**：H3 半尺寸直出 + 全尺寸精修（FL2VA 架构），兼顾速度与画质
- **条件注入体系**：首尾帧 / 多参考图混合条件，支持 1~N 张参考图自由组合
- **6bit MLX 量化**：DiT 主干量化推理，显存占用与速度均大幅优化
- **SOL 稀疏注意力**：注意力计算本体优化，降低长序列开销
- **PAB 广播（Post Attention Broadcast）**：跨步缓存广播，跳过冗余注意力计算
- **视频延续生成**：落盘 latent 缓存文件（`.h3cc` v2）实现节点链式延续，链路间资源继承——视频 1 的条件资源自动递增传递给视频 1+n；缓存按资源 id 去重，避免重复注入
- **视频节点唯一连线**：视频节点只能连到一个视频节点，超限自动拦截并提示

### 视频增强与进阶采样

- **H3-to-LTX Latent Adapter**：H3 生成结果经 latent 桥接送入 LTX2.5 二次细化（像素桥二采）
- **SelfLift 进阶采样**：自举渐进式采样，提升细节与一致性
- **CQEnhancer（LTX 专属）**：画质增强模块
- **ICLoRA（LTX 专属）**：可控生成 LoRA
- **Apple 超分二采**：系统级超分管线二次采样，输出更高分辨率

### 图像生成

- **HiDream**：高质量文生图 / 图生图
- **Z-Image**：轻量图像生成

### 工作流与工程

- **无限画布**：节点拖拽、连线、分组、大纲视图、撤销/快照
- **模型下载管理器**：H3 / HiDream 等模型一键下载
- **量化工具脚本**：模型量化辅助工具

## 性能参考

M4 Max 下实测（4 张参考图，720p 5s 视频）：

| 阶段 | 速度 |
|------|------|
| 半尺寸 | 约 100 s/it |
| 全尺寸 | 约 450 s/it |
| 单条视频总耗时 | 约 18 分钟 |

> 速度优化不牺牲质量：分辨率、帧数、采样步数均为硬约束，优化集中于 GEMM 效率、注意力计算、同步点/内存管理与 MLX 编译预热。
